## What is Code Coach?

Code Coach is a VS Code extension that explains code you didn't write. It provides:

- **Plain-English Explanations** - Line-by-line breakdowns with citations
- **Debugging Guidance** - Trace errors to their root cause
- **Team Collaboration** - Share understanding across your team
- **Privacy-First Design** - Works offline, your code stays local

Whether you're a new team member, maintaining legacy code, or reviewing AI-generated code, Code Coach helps you understand what's happening and why.

## Feature Categories

### Core Features (Free)
Essential tools for individual developers:
- Explain Selection
- Explain Why This Works
- Explain Diagnostics
- Deep Dive Analysis
- Code Smells Detection
- Test Gap Finder
- Coach Mode

### Team Intelligence (Team Plan)
Collaboration tools for development teams:
- Explanation Templates
- Team Pinned Symbols
- Explain Diff
- Onboarding Tours
- Change Subscriptions
- Shared Explanation Cache
- Knowledge Graph

### Enterprise Features
For organizations with compliance requirements:
- SSO Integration (Azure AD, Okta, Auth0, Google)
- Custom Model Endpoints (Azure OpenAI, AWS Bedrock, vLLM)
- Audit Logging
- Role-Based Access
